# 角色卡状态

对战与观战共用状态目录、图标组件、效果说明和显示时间计算。绿框表示增益，红框表示减益；限时状态的环形进度为剩余时间占总时长的比例。常驻状态保持完整圆环，说明结束条件；护盾圆环表示剩余次数，抓痕角标表示叠层。混合效果拆成增益和减益，不以单一颜色掩盖代价。

桌面上鼠标悬停、键盘聚焦或点击图标均可查看说明。点击固定说明，外部点击或 Esc 关闭；驱散、击沉、退出和页面卸载会清理对应图标与浮层。选舰按钮和状态图标是同一卡片内的独立控件，待分离、禁控时仍可阅读状态，阅读不会切舰。矮屏桌面使用单行滚动；移动端（窄屏或粗指针）不显示 buff 图标和说明，保持原操作区布局。

## 开发边界

- `shared/game/status-effect-definitions.js`：稳定 ID、正负性质、图标语义、效果说明、常驻结束条件。不得在此改变规则。
- `shared/game/status-effects.js`：从真实舰船/舰队状态读取当前效果，输出 `id`、`expiresAt`、`duration`、`remaining` 以及层数/倍率等公开参数。击沉不输出状态，过期状态不输出；不能推进计时、清理状态或写回模拟。
- `Ship.serialize()`：统一提供 `statusEffects`，旧 `buffs` 名称数组从同一结果生成。无需分别添加单人、服务端或观战分支。
- `src/battle/status-effect-timing.js`：仅在显示副本中处理插值与有限外推。当前权威帧已删除的效果不能复活；续期采用新的结束时间，常驻状态不自造时长。
- `src/battle/status-effects.js` / `.css`：按 ID 复用图标节点、进度环、叠层、桌面交互及顶层效果浮层。HUD 和观战只传入当前舰船快照；页面编排器只挂载/卸载浮层。

新增状态先在规则所属模块实现效果，再在目录定义 ID 与说明、在权威序列化入口绑定实际寿命/参数，补齐中英日文字和专项样例。使用现有图标语义时无需修改 UI；确需新图标只扩展共享图标目录。对局结果改变时才更新 `RULESET_VERSION`，仅增加公开显示字段不升规则版本。

`npm run test:ui:status` 覆盖完整目录、实际技能施加、权威寿命、净化/涤除、常驻支援、击沉、续期/插值不写回、桌面对战/观战一致、禁用选舰仍可阅读、悬停/键盘/点击、移动端隐藏、五种视口和卸载。`test:ui:command` 验证真实单人技能产生正负图标；`test:ui:spectator` 验证本地真实 WebSocket 的形态正负效果及玩家模式恢复。它们不代表远程网络或物理设备验收。
