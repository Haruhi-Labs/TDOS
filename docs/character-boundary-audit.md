# 以角色为中心的内部边界复查

2026-10-11，复查起点为 `c114949`，本轮实现截至 `648c5e0`。结论：前两轮未完成所有角色内部边界重构。本轮处理了实体推进、组件清理、侦察机创建和破盾交互中的遗漏，仍有舰队级角色逻辑与复合角色状态需要进一步收口，不能把导入检查通过等同于架构全部完成。

## 检查方法与消费时机

逐个检查九个可选角色的旗舰/副舰入口，并追踪伴随舰、支援弹体、舞台受影响者：创建与派生属性 → 输入与支付 → 状态生效 → 移动/接触/攻击 → 净化/死亡/转队 → 快照与 AI/显示消费。检查实际字段的写入点和顺序，不只检查循环导入。

- **角色能力**：解释具体角色状态，供移动、回能、攻击、碰撞等流程只读查询；读取不得过期清理、扣费或推进状态。
- **角色效果**：在确定的权威阶段同步提交。基础伤害后立即处理命中效果；冲撞能力消费成功后才破盾；同 tick 刚生效的技能仍保留净化保护。
- **领域实体**：持有并提交生命、资源、位移、冷却、集合归属等基础状态。角色效果通过领域操作改变这些状态。
- **投影**：将权威状态转为角色摘要与协议字段，不参与战斗推进。字段名可以包含角色语义；底层移动和弹体命中流程不应据此识别角色。

不是把所有状态延后到帧末统一消费。现有规则依赖即时结算及确定顺序，改变消费时机可能改变开火资格、后续碰撞、护盾次数和胜负。

## 本轮四个实现提交

1. `bb0f6b1`：基础移动、航线、射界、回能、视野、射速和弹体配置消费角色能力。
2. `2de5c71`：舰船不再直接导入角色运行时；创建、净化、专属移动、猫爪命中和投影分别交给专属模块及装配契约。
3. `2e53037`：侦察机生成消费机体配置；专属变身与公共副舰技能统一提交到舰队成功入口，保留各自支付规则。
4. `648c5e0`：护盾不再识别其他角色，读取冲撞描述后通过效果入口消费；刀锋接触历史从舰船临时字段移为效果模块私有数据。

新增的适配层是本游戏的权威装配代码，仍能读取实时实体。它不等于所有组件已经物理私有，也不应宣称任何模块都无法绕开操作入口。静态守卫新增舰船/弹体/侦察机的导入限制，行为测试验证可替换契约、消费顺序和只读查询；二者不能替代对剩余写入点的审查。

- 朝比奈1096：形态转换与光线各自拥有创建、推进、取消、结算和投影；舰队只提供资源、实体查询和施放提交能力。春日支援调用相同光线能力，不依赖未来角色实现。
